# Miguel Nieto

Senior fullstack engineer from Colombia, building on Stellar and Soroban. I work mostly in Elixir, TypeScript and Rust.

## What I'm building

- [Writz](https://github.com/WritzProtocol/writz) is Bitcoin lending on Stellar. Borrow USDC against native BTC with no bridge, no custodian and no wrapped Bitcoin.
- [LumenWipe](https://github.com/LumenWipe/lumenwipe) closes any Stellar account and recovers the XLM locked inside it. You keep your keys the whole time.
